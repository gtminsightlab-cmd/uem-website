# LaunchOS Readiness Question Bank v0

**Count:** 192 candidate questions  
**Workstreams:** 16  
**Status:** Build input — not final validated pharma methodology.

The purpose of v0 is to make the Conviction Prototype meaningful while keeping every question, weight, gate, evidence expectation, and applicability rule configurable.

## Validation rules

- No question is immutable.
- Hard gates are candidates until operator/expert validation.
- Weight values are candidates.
- Launch archetype can change applicability and weighting.
- Time-to-launch can change severity.
- Evidence grade changes confidence.
- No external claim that “X score predicts launch success” is allowed from v0.

## Review workflow

For each workstream:
1. Founding operator review.
2. Specialist expert review where applicable.
3. Remove duplicates/low-value questions.
4. Identify missing questions.
5. Validate candidate hard gates.
6. Validate evidence expectations.
7. Define expected timing by launch phase.
8. Define archetype applicability.
9. Approve methodology version.
10. Test against synthetic/historical launch.
11. Test against first paid engagement.

The CSV file is the machine-ready seed source.
