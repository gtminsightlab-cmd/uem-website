# Wave 1 — Conviction Prototype

## Goal
Create a **real working vertical slice** deep enough that an experienced pharmaceutical commercial leader understands LaunchOS value within 15 minutes.

This is not Figma, a static mock, or a hard-coded demo.

## Required Modules
1. Command Center Lite
2. Readiness Engine v1
3. Launch Archetype v1
4. Gap Wizard v1
5. Expert Engagement v1
6. Rules Manager v1
7. Roadmap / Critical Path v1
8. Decisions & Risks v1
9. Build / Buy / Rent v1
10. Executive Readiness Report
11. Help / Industry Terminology
12. Ask LaunchOS v1

## Core Demo Journey
A user should be able to:
- open the seeded first-U.S.-launch tenant,
- understand overall launch state,
- inspect why a workstream is red/yellow/green,
- ask “How many reps should we hire?”,
- see LaunchOS refuse false precision because required inputs are missing,
- generate an Expert Engagement,
- edit a methodology rule and preview its impact,
- move a milestone and see downstream dependencies,
- compare Internal vs CSO vs Hybrid,
- record a decision,
- generate an executive report.

## Success
The product creates enough conviction to generate one of two useful outcomes:
1. Experienced operators say “this would materially improve launch planning/execution”; or
2. They identify where the product is naive, redundant, or low-value before material capital is spent.
