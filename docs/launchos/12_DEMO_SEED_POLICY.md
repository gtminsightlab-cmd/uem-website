# Demo Seed Policy

The demo tenant proves the production architecture.

## Rules

- Demo tenant is created via seed script.
- Demo users are created via seed script.
- Demo product/launch are database records.
- Demo readiness answers are records.
- Demo rules are normal Rules Manager records.
- Demo milestones use normal methodology/template records.
- Demo experts are normal expert records flagged as demo.
- Demo AI calls use real product services operating on demo data.
- No fake static AI result is rendered as if generated.
- Demo reports use the production report renderer.

## Demo Tenant Candidate

A fictional global specialty-biopharma company entering the U.S. for its first branded launch.

Keep:
- company fictional,
- product fictional,
- clinical/commercial scenario realistic,
- no resemblance intended to one active manufacturer.

The demo must be removable without affecting application behavior.
